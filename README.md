# china-a-share-size-factor
中国A股规模因子实证检验：基于市值排序构建十分位组合，并检验 Small-Big 收益及其统计显著性。
# 中国A股规模因子检验

本项目基于中国A股月度股票数据，对**规模因子（Size Factor）**进行实证检验。

研究目标是按照股票总市值进行分组，比较小市值股票与大市值股票的后续收益差异，并检验中国A股市场中是否存在显著的规模效应。

## 研究思路

在每个月末，根据股票的**滞后一期总市值**对全部股票进行排序，并划分为10个投资组合：

- 第1组：市值最小的股票（Small）
- 第10组：市值最大的股票（Big）

在此基础上分别计算：

- 等权组合收益
- 市值加权组合收益
- Small − Big 多空组合收益

规模因子的基本定义为：

$$
SMB_t = R_{Small,t} - R_{Big,t}
$$

其中：

- \(R_{Small,t}\)：小市值组合在 \(t\) 月的收益率
- \(R_{Big,t}\)：大市值组合在 \(t\) 月的收益率

如果 Small − Big 的平均收益显著为正，则说明样本期内存在一定程度的小市值效应。

## 样本筛选

在构造投资组合前，对股票样本进行了筛选和清洗。当前版本主要包括以下处理：

- 剔除 ST、*ST 等风险警示股票
- 剔除每股净资产小于或等于0的股票
- 剔除上市不足252个交易日的股票
- 剔除调仓日处于涨停或跌停状态的股票
- 对月度横截面的总市值和总股本进行1%和99%分位数缩尾处理
- 识别月末停牌股票，并对停牌期间收益进行相应处理

对于发生停牌的股票，程序根据停牌前最后一个可交易价格和复牌后的可交易价格计算区间收益，并对停牌期间涉及的月份进行处理，以尽量避免直接将缺失收益简单设为0。

## 投资组合构造

每个月 \(t\) 的基本流程如下：

1. 计算股票总市值；
2. 使用上一期总市值 \(MCAP_{t-1}\) 作为排序变量；
3. 按市值从小到大划分为10组；
4. 分别计算各组的：
   - 等权收益率；
   - 滞后市值加权收益率；
5. 构造 Small − Big 组合；
6. 对组合平均收益进行显著性检验。

为避免当期信息影响组合构造，排序和市值加权均使用滞后一期市值。

## 显著性检验

考虑到月度组合收益可能存在异方差和序列相关，本项目采用 **Newey–West HAC 标准误**进行统计推断。

当前设置的最大滞后阶数为6个月。

主要关注 Small − Big 组合平均收益的：

- 均值
- Newey–West t统计量
- 统计显著性

## 当前结果

当前版本得到的月均收益如下：

| 组合                          |    等权收益 | 市值加权收益 |
| ----------------------------- | ----------: | -----------: |
| Small                         |     2.4743% |      2.4367% |
| Big                           |     0.6869% |      0.6785% |
| Small − Big                   | **1.7874%** |  **1.7582%** |
| Small − Big 的 Newey–West t值 |  **4.0642** |   **3.7573** |

从当前结果看：

- 小市值组合的平均收益明显高于大市值组合；
- 从小市值组到大市值组，组合收益整体呈下降趋势；
- Small − Big 收益在等权和市值加权口径下均为正；
- Newey–West 调整后的 t 统计量均显示较强的统计显著性。

因此，在当前样本和当前研究设定下，中国A股市场表现出较为明显的规模效应。

需要说明的是，以上结果基于当前版本的数据处理和组合构造方法。随着后续对样本筛选、停牌处理、交易约束和因子构造方法的进一步调整，结果可能发生变化。

## 方法说明

在因子实证研究中，样本构造方式会显著影响最终结果。本项目在实现过程中重点考虑以下问题：

### 1. 避免前视偏差

涉及公司财务信息时，尽可能按照财务数据的实际公告时间进行匹配，而不是直接按照财务报告期使用尚未公布的信息。

### 2. 使用滞后市值排序

组合在 \(t\) 月的构造基于 \(t-1\) 月已经能够观察到的市值信息，以减少前视偏差。

### 3. 考虑中国A股交易制度

在样本筛选过程中考虑：

- ST制度
- 新股上市
- 涨跌停限制
- 停牌

这些制度因素可能显著影响因子投资策略的实际可交易性。

### 4. 对时间序列相关性进行调整

组合收益的显著性检验采用 Newey–West 标准误，以降低异方差和自相关对统计推断的影响。
